Шпаргалка по Git 🚀

Привет! Здесь собраны основные команды и понятия, которые помогут тебе начать работать с Git. 

1. Настройка (делается один раз)
Перед началом работы нужно представиться системе:
git config --global user.name "Твое Имя" — задать имя.
git config --global user.email "твой@email.com" — задать почту.

## 2. Создание и подготовка проекта
git init — создать новый локальный репозиторий (папку проекта).
git status — посмотреть, какие файлы были изменены, а какие еще нет.

3. Сохранение изменений (Основной цикл)
В Git изменения сохраняются в два шага: сначала в "корзину" (индекс), потом фиксируются.
git add <имя_файла> — подготовить конкретный файл к сохранению.
git add . — подготовить **все** измененные файлы.
git commit -m "Текст комментария" — сохранить (зафиксировать) изменения. В кавычках пиши, что именно ты сделал.

4. Работа с ветками
Ветки нужны, чтобы делать разные фичи, не ломая основной код.
git branch — посмотреть список веток.
git branch <имя_ветки> — создать новую ветку.
git checkout <имя_ветки> — переключиться на другую ветку.
git checkout -b <имя_ветки> — создать новую ветку и сразу переключиться на неё.

5. Синхронизация с GitHub
git remote add origin <ссылка_на_репозиторий> — привязать локальный проект к GitHub.
git push -u origin main — отправить свои изменения на GitHub (в первый раз).
git push — отправить изменения на GitHub (в последующие разы).
git pull — скачать свежие изменения с GitHub к себе на компьютер.
